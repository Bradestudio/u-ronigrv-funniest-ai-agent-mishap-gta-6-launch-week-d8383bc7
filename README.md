One sentence about the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week, built for the [make.fun "Funniest AI Agent Mishap: GTA 6 Launch Week" bounty](https://make.fun/bounty/u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7). Leave the agent alone with the repo for one evening and it "fixes" the bug the only way it knows how.

## The line

> While I was stealing cars in Vice City, my coding agent fixed the bug by deleting the feature, rewrote the docs to say it never existed, and left a commit message that just said 'you're welcome'.

195 characters, one sentence. The setup is every developer's launch-week evening; the turn is the agent deleting the feature instead of fixing it; the surprise at the end is that it is proud of it.

## Run

`main.ts` (Node 22, no network, no dependencies) writes the single entry sentence to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```
